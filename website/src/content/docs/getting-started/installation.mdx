---
title: Installation
description: Install the Ward native binary or build it from source.
---

Ward supports Java/Maven and Java/Kotlin Gradle projects. The native binary needs no JVM; the executable jar
requires JDK 25.

## Install script (Linux and macOS)

```bash
curl -fsSL https://raw.githubusercontent.com/RicardoRB/ward-ai/main/install.sh | sh
ward --version
```

The script detects your OS and CPU, downloads the matching release archive from GitHub Releases,
verifies its SHA-256 checksum, and installs it as `ward` in `~/.local/bin`. The archive's
`LICENSE` and `NOTICE` go to `~/.local/share/doc/ward`. Releases before `v0.0.7` predate the
archives and can't be installed with the script. If that directory is not on your
`PATH`, the script prints the line to add to your shell profile. It supports Linux x86_64 and macOS
(Apple Silicon and Intel).

When it finishes, the script prints the command that installs the Ward
[agent skills](/integrations/agent-skills/). It only prints the command and does not run it:

```bash
npx skills add RicardoRB/ward-ai --skill ward-init ward-tune
```

Then run `/ward-init` in your coding agent to set up Ward together with it.

| Variable | Default | Purpose |
|---|---|---|
| `WARD_VERSION` | `latest` | Release tag to install, for example `v0.1.0`. |
| `WARD_INSTALL_DIR` | `~/.local/bin` | Directory for the `ward` binary. |
| `WARD_DOC_DIR` | `<install dir parent>/share/doc/ward` | Directory for `LICENSE` and `NOTICE`. |
| `WARD_BASE_URL` | GitHub Releases | Download base URL, for mirrors. |

```bash
curl -fsSL https://raw.githubusercontent.com/RicardoRB/ward-ai/main/install.sh \
  | WARD_VERSION=v0.1.0 WARD_INSTALL_DIR=/usr/local/bin sh
```

## Manual download

Each [GitHub release](https://github.com/RicardoRB/ward-ai/releases) publishes a native archive
per platform with a `.sha256` checksum file. Each archive contains the binary, `LICENSE`, and
`NOTICE`:

| Platform | Asset |
|---|---|
| Linux x86_64 | `ward-linux-x86_64.tar.gz` |
| macOS Apple Silicon | `ward-macos-aarch64.tar.gz` |
| macOS Intel | `ward-macos-x86_64.tar.gz` |
| Windows x86_64 | `ward-windows-x86_64.zip` |

`LICENSE` and `NOTICE` are also attached to each release.

```bash
curl -fsSLO https://github.com/RicardoRB/ward-ai/releases/latest/download/ward-macos-aarch64.tar.gz
curl -fsSLO https://github.com/RicardoRB/ward-ai/releases/latest/download/ward-macos-aarch64.tar.gz.sha256
shasum -a 256 -c ward-macos-aarch64.tar.gz.sha256
mkdir ward && tar -xzf ward-macos-aarch64.tar.gz -C ward
mv ward/ward ~/.local/bin/ward
```

On Windows, download `ward-windows-x86_64.zip`, extract it, and place `ward.exe` in a
directory on your `PATH`.

## Build from source

Requires JDK 25. Maven is provided by the repository wrapper.

```bash
git clone https://github.com/RicardoRB/ward-ai.git
cd ward-ai
./mvnw package
java -jar target/ward.jar --version
```

To build the native binary `target/ward`, use GraalVM 25:

```bash
./mvnw -Pnative -DskipTests native:compile
```

Picocli's annotation processor generates the native reflection metadata during compilation. New CLI
commands and options are included from their annotations; no manual command metadata entry is needed.

Agent integrations invoke `ward` by name, so the binary (or a wrapper script that runs the jar)
must be on `PATH`. See [quick start](/getting-started/quick-start/) to run your first check.
