---
title: Installation
description: Build Sentinel from source and run the CLI.
---

Sentinel currently supports Java 25 and Maven projects. Maven is provided by the repository wrapper.

```bash
git clone https://github.com/sentinel-ai/sentinel-ai.git
cd sentinel-ai
export JAVA_HOME=/path/to/jdk-25
./mvnw package
```

The executable jar is `target/sentinel.jar`; use `bin/sentinel` as the repository launcher. A native
binary can optionally be built with GraalVM 25:

```bash
./mvnw -Pnative -DskipTests native:compile
```

Picocli's annotation processor generates the native reflection metadata during compilation. New CLI
commands and options are included from their annotations; no manual command metadata entry is needed.

See [quick start](/getting-started/quick-start/) to detect a project and run its first check.
