---
title: Quality hooks
description: Opt-in local Git hooks for Ward quality profiles.
---

`ward init --quality-hooks` installs local hooks for the phase profiles generated by init:

```sh
ward init --integration none --gate format,tests --quality-hooks
```

- `.git/hooks/pre-commit` runs `ward check --profile pre-commit --format json` after the shebang and before existing hook logic.
- `.git/hooks/pre-push` runs `ward check --profile pre-push --format json` after the shebang and before existing hook logic.
- Compilation is intentionally part of `pre-push` (and `ci`), not `pre-commit`; the fast commit hook avoids paying for a compile on every edit.
- Hooks report results as JSON on stdout so a coding agent that commits or pushes can read which findings to fix.
- A failed check returns non-zero and blocks the commit or push.

Ward uses marker-bounded sections. Existing user hook content and executable permissions are
preserved. Re-running `--quality-hooks` refreshes both managed sections without adding duplicates.
To remove only Ward's quality sections, run:

```sh
ward init --remove-quality-hooks
```

This does not remove unrelated user content or other Ward-managed integrations. If a hook has
an incomplete or duplicate Ward quality marker, initialization reports a conflict and leaves
the hook unchanged; repair the markers manually before retrying.
