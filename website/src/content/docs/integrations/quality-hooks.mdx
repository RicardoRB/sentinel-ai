---
title: Quality hooks
description: Opt-in local Git hooks for Sentinel quality profiles.
---

`sentinel init --quality-hooks` installs local hooks for the phase profiles generated by init:

```sh
sentinel init --integration none --gate format,tests --quality-hooks
```

- `.git/hooks/pre-commit` runs `sentinel check --profile pre-commit`.
- `.git/hooks/pre-push` runs `sentinel check --profile pre-push` before existing hook logic.
- A failed check returns non-zero and blocks the commit or push.

Sentinel uses marker-bounded sections. Existing user hook content and executable permissions are
preserved. Re-running `--quality-hooks` refreshes the managed sections without adding duplicates.
To remove only Sentinel's quality sections, run:

```sh
sentinel init --remove-quality-hooks
```

This does not remove unrelated user content or other Sentinel-managed integrations. If a hook has
an incomplete or duplicate Sentinel quality marker, initialization reports a conflict and leaves
the hook unchanged; repair the markers manually before retrying.
