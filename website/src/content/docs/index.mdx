Sentinel runs the quality checks declared in `sentinel.toml` and reports clear results for people
or automation. It also provides project-local integrations for Claude Code and OpenCode.

## What you can do

- Detect supported Java/Maven projects and initialize configuration.
- Run configured quality gates as text or machine-readable JSON.
- Install agent hooks that run checks after edits and writes.

Start with [installation](/sentinel-cli/getting-started/installation/) or jump to [configuration](/sentinel-cli/configuration/sentinel-toml/).
