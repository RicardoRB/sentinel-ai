---
title: init
description: Create sentinel.toml and select integrations.
---

`sentinel init` creates `sentinel.toml` using an interactive wizard or explicit options.

```sh
sentinel init [-C <dir>] [--preset <standard|strict>] [--integration <none|agent>[,...]] [--quality-hooks] [--remove-quality-hooks] [--gate <id>[,...]] [--tool openspec] [--openspec-validation <openspec|openspec-archived>[,...]] [--install-tool openspec] [--architecture <style>] [--overwrite] [--yes]
```

`agent` accepts the IDs documented for [`integrate`](/commands/integrate/), including `codex`, `cursor`,
`copilot`, `gemini`, `windsurf`, `cline`, `factory-droid`, and `amp`.

The gate selector accepts supported [gate IDs](/configuration/gates/). `none` is exclusive with
agent integrations. `archunit` prompts for Layered, Hexagonal, or Clean architecture and creates a
minimal `ArchitectureTest.java` only if one is absent. Existing configurations are preserved unless
overwrite is confirmed or `--overwrite` is supplied. Initialization does not install tools or run
gates. `standard` and `strict` presets pre-select their offline gates; `custom` starts with no gates selected. `zap` writes a `<TARGET_URL>` placeholder that you must replace
with an authorized target before `check` will run it. For `format`, `enforcer`, `license`, `api-compat`, and
`pmd`, missing Maven plugins are added to `pom.xml` using Sentinel's embedded Java/Maven compatibility catalog.
For Gradle projects, equivalent pinned plugin declarations are added to `build.gradle` or
`build.gradle.kts` using the detected DSL, and the Gradle Wrapper is preferred when available.
Existing compatible plugin versions are preserved. Incompatible managed plugins show the current version,
selected compatible version, detected constraints, and affected file before asking for consent. `--yes`
accepts these validated compatibility updates without prompting; it does not bypass unresolved prerequisites
or install standalone binaries such as Semgrep, Gitleaks, Trivy, or ZAP. Declined updates leave the POM
unchanged and report that the selected gate was not reconfigured. Preset rule files are Sentinel-owned;
unmarked existing files are preserved and reported. `--gate` adds gates to a preset. `-C <dir>` selects the
project directory. Exit codes: `0` success, `2` invalid usage or
inability to initialize (including cancelled or invalid selection).

Maven plugins are added only to the project-level `<build><plugins>` and dependencies only to the
project-level `<dependencies>`. Profiles, `pluginManagement`, `dependencyManagement`, and plugin
dependencies are never edited, and missing `<build>`, `<plugins>`, or `<dependencies>` sections are
created. New declarations match the file's indentation. The rest of `pom.xml` is left byte for byte as
it was. Before writing, Sentinel checks the edited `pom.xml` in-process, without running Maven or
fetching anything: the file must be well-formed XML, and each added declaration must contain only
elements Maven allows there. If a check fails, `pom.xml` is not written, the error names the tool being
added, and init rolls back its other changes. POMs with a `DOCTYPE` declaration are not edited
automatically; add those declarations by hand. Compatibility version updates change only the managed
plugin's own project-level `<version>`. A plugin declared only inside a profile is reported as not
reconfigured.

Init-generated configurations assign gates to cumulative execution phases. Fast gates (`format`,
`compile`, `checkstyle`, `pmd`, and `gitleaks`) belong to `default`, `pre-commit`, `pre-push`, and
`ci`. Slower local gates belong to `pre-push` and `ci`; environment-dependent gates belong to `ci`,
and custom commands belong to `pre-push` and `ci`. The `default` profile is intentionally the same
fast tier as `pre-commit`, while `ci` contains every selected gate. Init does not generate a CI
workflow.

The generated `gitleaks` command writes a redacted SARIF report so `sentinel check` can attach
structured findings (file, line, and rule) to a failed gate:

```toml
[quality-gates.gitleaks]
command = ["gitleaks", "detect", "--no-banner", "--redact",
           "--report-format", "sarif", "--report-path", "target/gitleaks.sarif"]
```

Gradle projects use `build/gitleaks.sarif`. Sentinel creates the report directory before the gate
runs, so the gate works on a fresh clone. Configurations generated by earlier versions keep working
without findings; re-run `sentinel init` or add the four report arguments to enable them.

Quality hooks are separate from agent integrations and are opt-in. Pass `--quality-hooks` to add
Sentinel-managed checks to `.git/hooks/pre-commit` and `.git/hooks/pre-push`. Each managed section is
inserted after the shebang and before existing user logic; it does not replace the hook. The
pre-commit section runs `sentinel check --profile pre-commit`, and the pre-push section runs
`sentinel check --profile pre-push`. Re-run the option to refresh the managed sections. Use
`--remove-quality-hooks` to remove only Sentinel's marked sections, preserving user content,
executable permissions, and other Sentinel integrations. A malformed or duplicate quality-hook marker
is reported as a conflict and left unchanged.

On supported macOS and Linux terminals, use Up/Down to move, Space to toggle, and Enter to confirm.
Press `q`, `Q`, or Ctrl+C to cancel. On Windows, piped input, or when raw terminal mode is unavailable,
the wizard uses numbered prompts instead.

The wizard has a separate optional Tools screen. OpenSpec, its active validation
(`openspec validate --all --strict --no-interactive`), and its archived validation
(`openspec validate --archived --no-interactive`) are unselected by default. Selecting a tool or
validation is not installation consent. `--install-tool openspec` is explicit consent; without it
Sentinel only writes selected validations and reports manual remediation.
## Troubleshooting with verbose diagnostics

Add `--verbose` to the root command or `init` command to route initialization decisions to stderr.
Diagnostics identify ownership conflicts, applied changes, and rollback outcomes without printing
file contents:

```console
sentinel --verbose init
sentinel init --verbose
```
