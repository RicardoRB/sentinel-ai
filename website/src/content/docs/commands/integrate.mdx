---
title: integrate
description: Install or remove agent integrations.
---

```sh
sentinel integrate <opencode|claude-code> [-C <dir>] [--remove]
```

Without an agent argument Sentinel prompts for a choice. Installation is project-local and
idempotent. Generated files are ownership-marked: user-owned conflicting files are not overwritten,
and removal deletes only Sentinel-owned files. OpenCode's Sentinel-owned command is also removed.
Review [Claude Code](/integrations/claude-code/) and [OpenCode](/integrations/opencode/) details.
Exit `0` means success. A conflict or invalid usage returns `2` (Sentinel could not complete the operation).
